# Data

This project uses the public **Stroke Prediction Dataset** from Kaggle
(author: fedesoriano):

https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset

1. Download `healthcare-dataset-stroke-data.csv` from the link above.
2. Place it in this folder: `data/healthcare-dataset-stroke-data.csv`

The CSV is not committed to this repository (see `.gitignore`); please respect
the dataset's licence on Kaggle.

| Property | Value |
|---|---|
| Patients | 5,110 |
| Outcome | Stroke (binary), 249 events (4.87%) |
| Predictors with missing values | BMI (3.9%), smoking status (30.2%, coded "Unknown") |
